# Consideraciones legales y éticas

Este repositorio no sustituye asesoría legal.

- Utiliza información pública y accesible de forma legítima.
- Respeta la privacidad, los términos de servicio y las restricciones de cada plataforma.
- No realices ingeniería social, doxxing, acoso, acceso no autorizado ni explotación de vulnerabilidades.
- No recolectes ni publiques datos personales que no sean necesarios para un propósito legítimo.
- Solicita autorización por escrito antes de investigar activos corporativos, redes, dominios o cuentas.
- Para incidentes, conserva evidencia con integridad verificable y una cadena de custodia cuando corresponda.
