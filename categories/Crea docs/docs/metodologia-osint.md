# Metodología OSINT

## 1. Definir el objetivo

Establece un objetivo específico, legal y proporcional. Define el alcance, los activos autorizados y el resultado esperado.

## 2. Diseñar el plan

Determina las fuentes públicas pertinentes, las palabras clave, los indicadores técnicos y las condiciones de recolección.

## 3. Recolectar

Registra cada hallazgo con fecha, hora, URL, fuente, captura o hash cuando aplique. Evita recopilar datos personales innecesarios.

## 4. Verificar

Confirma los hallazgos con fuentes independientes. Distingue claramente entre hechos verificados, hipótesis e información no confirmada.

## 5. Analizar

Relaciona hallazgos, identifica contexto, evalúa confiabilidad y documenta limitaciones.

## 6. Reportar

Presenta resultados objetivos, reproducibles y con referencias. Incluye riesgos, impacto, evidencia y recomendaciones defensivas.
