# Inteligencia de amenazas

Recursos para analizar indicadores de compromiso, malware, URLs y campañas conocidas.

| Recurso | Uso |
|---|---|
| [VirusTotal](https://www.virustotal.com/) | Análisis y reputación de IOCs |
| [AbuseIPDB](https://www.abuseipdb.com/) | Reportes comunitarios de direcciones IP |
| [AlienVault OTX](https://otx.alienvault.com/) | Pulsos e indicadores de amenazas |
| [MalwareBazaar](https://bazaar.abuse.ch/) | Muestras y familias de malware |
| [URLhaus](https://urlhaus.abuse.ch/) | URLs maliciosas reportadas |
| [ThreatFox](https://threatfox.abuse.ch/) | IOCs relacionados con malware |
| [Cisco Talos Intelligence](https://talosintelligence.com/) | Reputación de dominios, IP y archivos |
| [MITRE ATT&CK](https://attack.mitre.org/) | Técnicas y tácticas adversarias |

## Manejo de evidencia

Evita descargar o ejecutar muestras maliciosas fuera de un laboratorio aislado y autorizado.
