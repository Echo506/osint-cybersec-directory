# Archivos y metadatos

| Recurso | Uso |
|---|---|
| [ExifTool](https://exiftool.org/) | Lectura y modificación de metadatos |
| [CyberChef](https://gchq.github.io/CyberChef/) | Transformación, decodificación y análisis de datos |
| [VirusTotal](https://www.virustotal.com/) | Análisis de reputación de archivos |
| [Hybrid Analysis](https://www.hybrid-analysis.com/) | Sandbox de archivos y URLs |
| [ANY.RUN](https://app.any.run/) | Análisis interactivo en sandbox |
| [HashMyFiles](https://www.nirsoft.net/utils/hash_my_files.html) | Cálculo de hashes en Windows |

## Buenas prácticas

Conserva el hash SHA-256, la fuente, la fecha de obtención y una copia original sin modificaciones de cada evidencia.
