# Geolocalización y verificación geográfica

Recursos para analizar ubicaciones mediante mapas, imágenes satelitales, datos públicos y fuentes geográficas abiertas.

| Recurso | Uso |
|---|---|
| [Google Maps](https://maps.google.com/) | Mapas, rutas, imágenes satelitales y Street View |
| [Google Earth](https://earth.google.com/) | Exploración 3D e imágenes históricas disponibles |
| [OpenStreetMap](https://www.openstreetmap.org/) | Cartografía colaborativa y datos geográficos abiertos |
| [Bing Maps](https://www.bing.com/maps) | Mapas e imágenes aéreas alternativas |
| [Mapillary](https://www.mapillary.com/) | Imágenes de calles aportadas por la comunidad |
| [Sentinel Hub EO Browser](https://apps.sentinel-hub.com/eo-browser/) | Imágenes satelitales Sentinel |
| [NASA Worldview](https://worldview.earthdata.nasa.gov/) | Capas e imágenes satelitales globales |
| [SunCalc](https://www.suncalc.org/) | Posición del sol y sombras según fecha y ubicación |
| [OpenWeatherMap](https://openweathermap.org/) | Datos meteorológicos actuales e históricos disponibles |
| [GeoNames](https://www.geonames.org/) | Base de datos de nombres geográficos |

## Método de validación

1. Identifica pistas visuales: rótulos, idioma, matrículas, edificios, relieve, vegetación, infraestructura y señalización.
2. Contrasta esas pistas con al menos dos fuentes independientes, como mapas, imágenes satelitales y fotografías públicas.
3. Verifica que la fecha, la iluminación, las sombras y el clima sean compatibles con la hipótesis.
4. Registra fuentes, enlaces, capturas, fecha de consulta y nivel de confianza.

## Privacidad

No uses estas herramientas para rastrear personas, vehículos o domicilios sin consentimiento, propósito legítimo y autorización correspondiente.
